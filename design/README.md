# Selfy デザイン仕様（Claude Code 向け）

Selfy は Cloudflare 上で動く、自分専用の写真ストレージ兼ビューワーです。
このフォルダは、デザインツールで作った画面デザインを実装用に書き出したものです。

## このフォルダの中身

- `screens/` … 各画面のデザイン（HTML）。見た目と挙動の「正解」として参照してください
- `images/` … ログイン画面やお気に入りで使っている写真（デザイン確認用のサンプル）

### `screens/*.html` の読み方

デザインツール独自の形式です。ブラウザで直接開いても正しく表示されません。
**コードとして読み、React コンポーネントに置き換えてください。**

- `<x-dc>` の中身がマークアップ。スタイルはインライン `style` にすべて書いてあります
- `{{name}}` … 下の `<script>` の `renderVals()` が返す値の差し込み
- `<sc-for list="{{items}}" as="item">` … 配列のループ（React の `map`）
- `<sc-if value="{{cond}}">` … 条件表示
- `onClick="{{handler}}"` … クリック時の処理
- `<dc-import name="X" view="...">` … 別画面を部品として読み込み（`view` は初期表示の切り替え）
- `<helmet>` … フォント読み込みとページ共通の CSS
- `this.state` / `setState` … React のクラスコンポーネントと同じ

## 画面一覧

| 画面 | パソコン | スマホ |
|---|---|---|
| ログイン | `Main.html` | `MobileLogin.html` |
| アルバム一覧 | `Albums.html` | `MobileAlbums.html` |
| アルバム内の写真一覧 | `Album.html` | `MobileAlbum.html` |
| 写真の拡大表示 | `Lightbox.html`（`Album.html` の `view="lightbox"`） | `MobileLightbox.html` |
| アルバムの共有 | `Share.html`（`Album.html` の `view="share"`） | `MobileShare.html` |
| お気に入り | `Favorites.html` | `MobileFavorites.html` |
| 設定 | `Settings.html` | `MobileSettings.html` |

`*Dark.html` は同じ画面のダークモード版です。レイアウトは同一で、色だけ違います。
**実装では画面を分けず、下の色トークンを CSS 変数にして切り替えてください。**

パソコン版とスマホ版も、別々に作らずレスポンシブな1つのコンポーネントにするのがおすすめです
（目安：幅 768px 未満でスマホのレイアウト）。

### 文字

- フォント：`Inter`（英数字）＋ `Noto Sans JP`（日本語）
- 見出し：32px / 700（スマホ 26〜30px）
- 本文：14〜15px、補助テキスト 12〜13px
- スマホの入力欄は 16px 以上（iOS の自動ズーム防止）

### 形・サイズ

- 角丸：ボタン（丸）22px、入力欄 12px、カード 16px、ダイアログ 20px、写真サムネイル 6〜8px
- タップ領域は最低 44px
- パソコンの本文の最大幅：1280px（設定画面は 720px）

## 挙動のポイント

- **ログイン**：背景で写真の列が途切れずに流れ続ける（パソコンは縦3列、スマホは横2段、列ごとに向きと速さが違う）。
  CSS アニメーションのみで実装し、写真の並びを2回繰り返して `translate(-50% - gap/2)` でループさせる。
  `prefers-reduced-motion: reduce` のときはアニメーションを止める
- **写真一覧**：撮影日ごとにまとめて表示。クリックで拡大表示を開く
- **拡大表示**：前後の写真へ移動、お気に入り、ダウンロード、詳細情報（パソコンは右パネル、スマホは下から出るシート）。
  スマホは左右スワイプで移動
- **共有**：アカウントのある人を選んで招待（権限は「閲覧のみ」か「写真の追加も可」）、リンク共有のオン／オフ、有効期限、ダウンロード可否
- **設定**：テーマ（自動／ライト／ダーク）、ログイン画面の写真、アップロード設定、ストレージ使用量、パスキーなど

## 写真について

`images/` の写真はデザイン確認用のサンプルです。顔が写っている写真も含まれるため、
アプリに同梱して配布する前に、各写真のライセンスを確認してください。
